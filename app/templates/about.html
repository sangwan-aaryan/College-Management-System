About This Project

This College Management System (CMS) is a full-stack web application built using Python, Flask, and MySQL. It is designed to demonstrate a complete, database-driven application with multiple user roles and permissions.

Core Features

  • Three User Roles: Admin, Teacher, and Student, each with a unique dashboard and set of permissions.
  • Admin Panel: Full CRUD (Create, Read, Update, Delete) functionality for managing Students, Teachers, Courses, and Subjects.
  • Faculty Portal: Teachers can mark daily attendance and submit student marks for their assigned subject.
  • Student Dashboard: Students can view their personal profile, check detailed attendance records, and see their final results/grades.
  • Dynamic Dashboards: Statistical summaries (total students, faculty, etc.) and charts (attendance percentage, grade distribution) powered by Chart.js.
  • Session Management: Secure login/logout functionality using Flask-Login to manage user sessions.

Technology Stack

  • Backend: Python with the Flask web framework.
  • Database: MySQL (connected via Flask-MySQLdb).
  • Frontend: HTML5, Tailwind CSS (for styling), and JavaScript.
  • Authentication: Flask-Login for handling user sessions and authentication.
  • Visualizations: Chart.js for rendering charts on the dashboards.

This project is organized as a Flask application package, with route modules, reusable forms and services, database configuration, templates, and static assets kept together under `app/`.
